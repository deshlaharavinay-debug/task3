# Web Development Project
A simple webpage made with HTML and CSS. It uses standard text tags, lists, links, and custom colors.

##  Features
Background Color: A nice orange-brown page color.
Text Styling:White paragraph text with dark blue headers.
Custom Highlights: Special words highlighted with yellow, purple, red, or blue.
Web Links: Links that open Google and UpskillMafia in new tabs.

##  Files
index.html` - The text and structure of the page.
style.css` - The colors, sizes, and design rules.

##  How to Open It
1. Save both files in the same folder.
2. Double-click `index.html`.
3. The page will open in your web browser.
